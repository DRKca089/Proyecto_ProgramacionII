Funcionalidad:
App para registrar productos, ventas, reportes, comprar.
Permite agregar productos, eliminarlos o modificarlos.
Permite comprar producto y visualizar las compras realizadas.
Incluye manejo de errores y eventos.
Información de los productos, usuarios, compras y detalles de compra se guardan en archivos de tipo csv.

Instrucciones:
1. Abrir la solución con Visual Studio 2022
2. Ejecutar el proyecto de presentación
3. Ingresas nombre y contraseña para iniciar sesión o registrarse para crear un nuevo usuario.
4. Navega usando los botones que habren formularios, cada formulario tiene una función en especifica.

Importate
*Las funciones varian si tu usuario tiene rol de administrador o de cliente*
